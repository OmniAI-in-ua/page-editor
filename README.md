# @omniai/page-editor

Ядро редактора сторінки манги — спільне для адмінки, сайту й бекенду MangaAI.

Редактор кладе поверх картинки тайпсетера **латки** (пікселі з очищеної сторінки, оригіналу чи колір)
і **текстові блоки** шрифтом Anime Ace. Стан правки (`EditorState`) — це JSON, з якого сторінку можна
звести однаково і в браузері, і на сервері.

## Що де

| Імпорт | Що | Де працює |
|---|---|---|
| `@omniai/page-editor` | типи стану, розкладка тексту з переносами, метадані бульбашок, малювання, операції зі станом, історія undo/redo | будь-де |
| `@omniai/page-editor/browser` | завантаження шрифту й метрики через canvas | браузер |
| `@omniai/page-editor/node` | реєстрація шрифту, зведення сторінки в PNG (`@napi-rs/canvas`) | Node (бекенд) |
| `@omniai/page-editor/vue` | `useEditor()` — контролер редактора: стан, вибір, інструменти, історія | Vue 3 |

Інтерфейс редактора (полотно, панель властивостей, сенсорна оболонка) — у застосунках: в адмінці свій,
на сайті свій. Спільні тут лише логіка й малювання.

## Шрифт

Файлу шрифту в пакеті немає: його ліцензія не дозволяє поширювати файл. Застосунок підключає свій:

```ts
// браузер
import { loadEditorFont } from '@omniai/page-editor/browser'
const font = await loadEditorFont('/fonts/Anime_Ace_v05_Regular.ttf')

// сервер
import { registerEditorFont, loadEditorImage, renderPagePng } from '@omniai/page-editor/node'
const font = registerEditorFont('/srv/fonts/Anime_Ace_v05_Regular.ttf')
const png = renderPagePng({ state, images: { auto, cleaned, original }, font })
```

## Навіщо зведення на сервері

Від читачів (спільнотна вичитка) приймаємо лише стан правки, а не готову PNG з браузера — інакше через API
можна підсунути будь-яку картинку. Сервер зводить сторінку тим самим кодом малювання, тож перевіряльники
бачать рівно те, що потрапить на сайт.

## Розробка

```bash
npm install
npm test          # Vitest: розкладка, переноси, метадані, стан, історія, зведення в Node
npm run typecheck
npm run build     # dist/: ESM (сайт, адмінка) і CommonJS (бекенд) з типами
```

Тест зведення в Node бере будь-який наявний TTF (`EDITOR_TEST_FONT` або системний), бо Anime Ace у пакеті немає.

У застосунках з Vite потрібен `resolve.dedupe: ['vue']`, щоб `@omniai/page-editor/vue` і застосунок
користувались одним екземпляром Vue.

## Версії й підключення

Версія в `package.json` = тег релізу (`v0.1.0`). Застосунки підключають пакет за тегом:

```json
"@omniai/page-editor": "github:OmniAI-in-ua/page-editor#v0.1.0"
```

Зібраний `dist/` лежить у репозиторії, тож під час встановлення нічого не збирається. Після змін у `src/`
обов'язково `npm run build` і закомітити `dist/` разом зі змінами — CI перевіряє, що вони збігаються.
